# CadFlux

CadFlux is an open-source browser-based CAD viewer and DWG/DXF-to-PDF
conversion tool.

CadFlux is based on the MLightCAD CAD Viewer and uses LibreDWG-based
components for DWG parsing.

## Features

- Open DWG and DXF files locally
- Browser-based CAD rendering
- Export model space to PDF
- Export paper-space layouts to PDF
- A0–A4 paper sizes
- Portrait and landscape output
- Fit-to-page and fixed-scale plotting
- Color and monochrome output
- Batch conversion
- No AutoCAD installation required
- No file upload required
